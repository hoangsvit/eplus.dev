As Meta expands Muse, its personal AI agent, more people are looking for invitation codes to explore the platform and potentially receive referral rewards.

But there's a problem: invite codes are scattered across social networks, GitHub discussions, and community posts. Some codes have limited uses, while others may no longer work.

💻 **GitHub:** <https://github.com/ePlus-DEV/muse-invite-hub>

## What Is Muse Invite Hub?

Muse Invite Hub is a free, open-source directory that makes it easier for the community to discover, copy, and share Muse AI invitation codes.

Instead of searching through hundreds of social media comments, users can explore community-shared codes from one place.

The project is independently developed and maintained by **ePlus.DEV**.

## What Can You Do?

🔎 **Discover invite codes** — Browse, search, and sort codes shared by the community.

📋 **Copy instantly** — Quickly copy an invite code and open Muse to redeem it.

🤝 **Share your code** — Contribute your invitation code through GitHub.

📊 **Community feedback** — Report whether a code worked and submit updated usage information.

🌍 **Country availability** — Check the countries where Muse has announced its rollout.

💻 **Open-source contributions** — Help improve the website, documentation, and user experience.

All code availability and usage information is community-reported. It is not a live connection to Muse's internal systems.

## Built with GitHub Pages and GitHub Actions

One of our goals was to keep the project simple, lightweight, and transparent.

Muse Invite Hub uses:

- **HTML, CSS, and JavaScript** for the user interface.
- **JSON** to maintain the public invitation-code directory.
- **GitHub Issues** for community submissions and feedback.
- **GitHub Actions** for validation, automated Draft Pull Requests, and deployment.
- **GitHub Pages** for static hosting.
- **Node.js 24** for testing and build automation, without requiring a backend or npm dependencies.

### A Community-Driven Contribution Workflow

When someone submits a code through GitHub, the automation can validate the submission and prepare a Draft Pull Request.

A maintainer reviews the proposed changes before they are merged.

Once an accepted code is published and verified on the live website, the contributor can receive a link to its dedicated detail page.

This keeps the project open to contributions while avoiding automatic publication of unreviewed content.
